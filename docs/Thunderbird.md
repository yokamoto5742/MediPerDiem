# Thunderbird による各医師へのメール一括送信

各医師のメールアドレスへ、月別の外来日当円の推移を Thunderbird の Mail Merge アドオンで一括送信する手順。差出人は yokamoto@shinseikai.or.jp、メールはプレーンテキスト形式とする。

## 仕組み

「集計を実行」すると、配信用CSVとは別に `data/各医師メール差し込み用.csv` が出力される(出力先は `config.ini` の `[Paths] mail_merge_csv`)。

- 列は `医師名, メールアドレス, 見出し, 4月, 5月, … , 3月`。
- 月の列には、前年度と今年度を横並びにした1行分の文字列が入る。値が無い月は空欄。
- 最新月の属する年度を今年度とする。2027年4月分からは自動で 2026年度 対 2027年度 に切り替わる。
- 列名は毎月変わらないので、テンプレートは一度作れば使い回せる。

メールの仕上がりは次のようになる。

```
内科 太郎　先生

先生の月別の外来日当円の推移を報告いたします。

月      2025年度    2026年度
４月    12,345円    13,456円
５月    12,345円    13,456円
６月    12,345円    13,456円
７月    12,345円    13,456円
８月    12,345円    13,456円
９月    12,345円

11月    12,345円
```

桁は半角空白でそろえている。等幅フォントでは完全にそろうが、受信側がプロポーショナルフォントで表示する場合、桁数の違う金額や前年度が空欄の行は少しずれる。

## 初回の準備

1. Thunderbird に yokamoto@shinseikai.or.jp のアカウントを設定し、Mail Merge アドオンを入れる。
2. アカウント設定 →「編集とアドレス入力」→「HTML 形式でメッセージを編集する」のチェックを外す(プレーンテキストで作成するため)。
3. 新規メッセージを作成し、次の内容を入力して「ファイル → 名前を付けて保存 → テンプレート」で保存する。
   - 差出人: yokamoto@shinseikai.or.jp
   - 宛先: `{{メールアドレス}}`
   - 件名: `医師毎の外来日当円月別推移`
   - 本文:

```
{{医師名}}　先生

{{医師名}}先生の月別の外来日当円の推移を報告いたします。

{{見出し}}
{{4月}}
{{5月}}
{{6月}}
{{7月}}
{{8月}}
{{9月}}
{{10月}}
{{11月}}
{{12月}}
{{1月}}
{{2月}}
{{3月}}

よろしくお願いいたします。

医療秘書課 岡本康宏
```

## 毎月の手順

1. アプリで「集計を実行」する。
2. Thunderbird でテンプレートを開き、差出人が yokamoto@shinseikai.or.jp であることを確認する。
3. 「Mail Merge」を押し、ソースに CSV、ファイルに `各医師メール差し込み用.csv`、文字コードに UTF-8 を指定する。
4. 配信モードは即送信ではなく「後で送信」か「下書きとして保存」にする。
5. 送信トレイ(または下書き)で数通を開き、宛先・医師名・金額が合っていることを確認してから送信する。

## 医局KPIメール(二村副院長宛て)

全医師の外来日当円の平均を、同じ Mail Merge の仕組みで二村副院長へ送る。

「集計を実行」すると `data/医局KPIメール差し込み用.csv` も出力される(出力先は `config.ini` の `[Paths] kpi_mail_merge_csv`)。

- データは1行だけで、列は `年月, 平均, 見出し, 4月, 5月, … , 3月`。
- `年月` は最新月(例: `2026年8月`)、`平均` はその月の平均(例: `12,599円`)。
- 平均は `常勤医師外来日当円平均の推移.xlsx` の「外来日当円平均」行と同じ値。配信先マスタに載っている医師の単純平均で、その月が空欄の医師は除く。
- 月の列の形式と年度の切り替わりは、各医師宛てと同じ。

メールの仕上がりは次のようになる。

- 差出人: yokamoto@shinseikai.or.jp
- 宛先: `二村明広 <akihirof@shinseikai.or.jp>`
- 件名: `医局KPI（医師平均日当円）`

毎月の手順は各医師宛てと同じで、テンプレートと、Mail Merge で指定するファイル(`医局KPIメール差し込み用.csv`)だけが違う。作成されるメールは1通。

## 初回に実機で確認すること

開発PCには Thunderbird が無く、差し込み結果は未確認。初回は差し込み用CSVを自分宛ての1行だけにしたコピーで試し、次の点を確認する。

- 連続した半角空白がそのまま残り、桁がそろって見えること。
- `名前 <アドレス>` 形式の宛先が正しく入ること。

## 採用しなかった案

- **HTML メールの表**: HTML メールが使えないため不採用。
- **アプリから SMTP で直接送信**: パスワードの保管が必要になり、送信前に実物を目視できない。
- **既存の配信用CSVをそのまま差し込みに使う**: 列名が年月なので、毎月テンプレートを手で直す必要がある。
