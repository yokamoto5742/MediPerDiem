# Thunderbird による各医師へのメール一括送信(計画)

各医師配信用外来日当円収益変化.csv に記載された各医師のメールアドレスへ、月別の外来日当円の推移を Thunderbird の Mail Merge アドオンで一括送信するための計画。未実装であり、末尾の未確定事項が決まってから実装する。

## 要件

- 差出人は yokamoto@shinseikai.or.jp とする。
- 送信にはできれば Thunderbird の Mail Merge アドオンを使う。
- 2025年度と2026年度を横並びにし、各月ごとに比較しやすくする。

## 現状

- 配信用CSVは 37名分で、列は `ID, 医師名, メールアドレス, 202504 … 202608`。メールアドレスは全員入力済みで、`名前 <アドレス>` 形式。
- 開発PCには Thunderbird が入っていないため、差し込みと送信の動作確認は開発PCではできない。

## 推奨案: Mail Merge 専用のCSVをアプリが追加出力する

今のCSVをそのまま使うと、列名が `202504` のような年月なので、月が増えるたび・年度が替わるたびにテンプレートを手で直すことになる。そこで列名を固定した差し込み専用CSVを別に出力し、テンプレートは一度作れば使い回せるようにする。

### 1. 差し込み用CSVを出力する

- `service/` に追加し、出力先は `config.ini` の `[Paths]` に1行追加する。
- 列は `医師名, メールアドレス, 前年度, 今年度, 前年度4月 … 前年度3月, 今年度4月 … 今年度3月` とする。
- 値は `12,345円` のように単位まで入れ、データが無い月は `-` にする。
- 最新月の属する年度を「今年度」とする。2027年4月分からは自動で 2026年度 対 2027年度 に切り替わる。
- 検証: pytest で、年度の切り替わり・未到来月・空欄を確認する。

### 2. テンプレート用のHTMLを用意する

`docs/` に置き、Thunderbird の「挿入 → HTML」で一度だけ貼り付けてテンプレート保存する。

| 月 | {{前年度}} | {{今年度}} |
|---|---:|---:|
| 4月 | {{前年度4月}} | {{今年度4月}} |
| 5月 | {{前年度5月}} | {{今年度5月}} |
| … | … | … |
| 3月 | {{前年度3月}} | {{今年度3月}} |

- 検証: 実機の Thunderbird で、自分宛てに1通だけ差し込んで表示を確認する。

### 3. 毎月の送信手順を README に書く

1. アプリで集計を実行する。
2. テンプレートを開き、差出人に yokamoto@shinseikai.or.jp を選ぶ。
3. Mail Merge で差し込み用CSVを指定する。
4. 配信モードは即送信ではなく「下書きとして保存」か「後で送信」にして、数通を目視してから送信する(別の医師の収益を誤送信しないため)。

## 採用しない案

- **アプリから SMTP で直接送信**: パスワードの保管が必要になり、送信前の目視確認もしにくい。
- **既存の配信用CSVをそのまま差し込みに使う**: コード変更は不要だが、毎月テンプレートを手で直す必要がある。
