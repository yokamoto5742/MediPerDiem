# 変更履歴

このプロジェクトのすべての重要な変更は、このファイルに記録されます。

フォーマットは [Keep a Changelog](https://keepachangelog.com/ja/1.1.0/) に基づいており、
バージョン番号は [Semantic Versioning](https://semver.org/lang/ja/) に従っています。

## [Unreleased]

## [0.6.0] - 2026-10-08

### 追加
- 変化表のバックアップ先フォルダを `config.ini` の `[Paths] backup_dir` で指定可能に(既定は `data/backup`。従来は変化表と同じ階層の `backup` フォルダ固定)

## [0.5.0] - 2026-10-08

### 追加
- 変化表に医師の行を追加した場合、完了ダイアログに追加した行の一覧(行番号・診療科・ID・医師名)を表示。実行結果欄の追加メッセージにも行番号を表示(行番号は「外来日当円」シートのもの)

## [0.4.1] - 2026-10-07

### 変更
- メール差し込み用CSVで、値が無い月は `-` ではなく空欄に変更

## [0.4.0] - 2026-10-07

### 追加
- Thunderbird の Mail Merge でプレーンテキストのメールを一括送信するための「各医師メール差し込み用.csv」を出力(前年度と今年度の外来日当円を月ごとに横並びにした行を持ち、値が無い月は `-`、出力先は `config.ini` の `[Paths] mail_merge_csv`。手順は `docs/Thunderbird.md`)

## [0.3.0] - 2026-10-07

### 追加
- 配信用CSVと同じ医師・月の表の下に、各月の合計と平均の行を加えた「常勤医師外来日当円平均の推移.xlsx」を出力(値は四捨五入した整数、合計・平均は数式、出力先は `config.ini` の `[Paths] average_workbook`)

### 変更
- 変化表に行が無い医師はスキップせず、同じ診療科の最終行の直下へ行を挿入(該当する診療科が無ければ表の末尾。内科は調整済みの値)

## [0.2.0] - 2026-10-07

### 追加
- IDが異なる同姓同名の医師は、IDが若い方へ外来収益と外来人数を合算(氏名の空白の違いは無視し、外来日当円は合計収益÷合計人数で算出)

### 変更
- 診療科目が健診(「健」)の行を集計対象外に変更

## [0.1.0] - 2026-10-06

### 追加
- 月次の外来収益ファイルを読み込み、変化表(外来日当円・外来収益合計)の対象月の列を更新
- 配信先マスタをもとに各医師配信用CSVを出力
- 更新前の変化表を `backup` フォルダへ自動バックアップ(`config.ini` の `[Backup] generations` で指定した世代数だけ保持、既定12世代)
